# AWDF Practical 7 — Task Manager

A full-stack task manager built with React and Vite on the frontend and Express, MongoDB, and JWT authentication on the backend.

## Run the backend

1. Open `TaskManagerAPI` and run `npm install`.
2. Copy `.env.example` to `.env` and set a strong `JWT_SECRET`.
3. Ensure MongoDB is running, then run `npm start`.

## Run the frontend

1. Open `TaskManager-frontend` and run `npm install`.
2. Run `npm run dev` and open the Vite URL (normally `http://localhost:5173`).

The API defaults to `http://localhost:3000`.
